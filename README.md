# Meu-Saldo

App web para registrar entradas e saídas de dinheiro, com saldo calculado automaticamente.

## Funcionalidades
- Adicionar entradas e saídas com descrição e valor
- Cálculo automático de saldo, entradas e saídas
- Remover transações
- Dados salvos no navegador (localStorage)
- Layout responsivo, inspirado em apps de banco

## Tecnologias
HTML, CSS e JavaScript, sem bibliotecas.
